### Verification process

<Steps>
<Step title="Open receipt">
  Click "View Receipt" to see the uploaded payment proof:
  
  <Frame>
  ```
  📸 PAYMENT RECEIPT - Order #12345
  
  [Receipt Image Display]
  
  Order Details:
  • User: @alisher_k
  • Amount: 15,000 RUB
  • Tickets: 10x VIP
  • Uploaded: 2024-01-20 14:30
  
  Expected Payment Details:
  • Card: 2202 2063 XXXX 1234
  • Amount: 15,000 RUB
  • Bank: Sberbank
  ```
  </Frame>
</Step>

<Step title="Verify information">
  Check the receipt for required information:
  
  <AccordionGroup>
  <Accordion title="✅ Verification checklist">
    - [ ] Card number matches (last 4 digits)
    - [ ] Amount is exactly 15,000 RUB
    - [ ] Transaction date is recent
    - [ ] Transaction ID is visible
    - [ ] Receipt is clear and readable
    - [ ] No signs of tampering
  </Accordion>
  
  <Accordion title="❌ Common issues">
    - Wrong amount transferred
    - Unclear or blurry photo
    - Missing transaction details
    - Wrong recipient card
    - Edited or fake receipt
    - Duplicate transaction
  </Accordion>
  </AccordionGroup>
</Step>

<Step title="Approve or reject">
  <Tabs>
  <Tab title="Approve">
    If verification passes, click "Approve":
    
    ```
    ✅ APPROVE PAYMENT
    
    Order #12345 will be approved.
    
    Actions that will be performed:
    • Mark payment as verified
    • Activate 10 VIP tickets
    • Send confirmation to user
    • Add to revenue statistics
    
    [Confirm Approval] [Cancel]
    ```
    
    <Check>
    Payment approved! User notified and tickets activated.
    </Check>
  </Tab>
  
  <Tab title="Reject">
    If verification fails, click "Reject" and provide reason:
    
    ```
    ❌ REJECT PAYMENT
    
    Order #12345 will be rejected.
    
    Rejection reason:
    [Dropdown: Select reason]
    • Wrong amount
    • Unclear receipt
    • Missing details
    • Wrong recipient
    • Suspicious activity
    • Other (specify)
    
    Additional notes:
    [Text area for detailed explanation]
    
    [Confirm Rejection] [Cancel]
    ```
    
    User receives notification with rejection reason and can upload a new receipt.
  </Tab>
  </Tabs>
</Step>
</Steps>

## Admin roles and permissions

<Tabs>
<Tab title="Super admin">
  **Full system access:**
  - All admin functions
  - User management
  - System settings
  - Create/delete admins
  - Access audit logs
  - Financial reports

  **Standard admin access:**
  - Payment verification
